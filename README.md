# CodeEvaluator — ソートアルゴリズム計算量判定システム

ソートアルゴリズムの Python プログラムを解析し、

1. **理論的な計算量オーダー** — AST(抽象構文木)の静的解析による導出
2. **実際的な計算量オーダー** — 実行時間の実測と曲線フィットによる推定

の両方を判定して比較表示する Streamlit ベースの Web アプリケーションです。

## 機能

- **ソート関数の自動検出**: 貼り付け・アップロードされたコードから、ソート関数らしい関数をスコアリングして検出します。
- **理論解析 (静的解析)**: ループの入れ子、while ループの更新パターン(半減 → O(log n) 等)、再帰の分類(半分割の分割統治 → O(n log n) 等)、`sorted()` や `list.insert` などの暗黙コストを合成して理論オーダーを導出し、**日本語の判定根拠**と信頼度を提示します。既知アルゴリズム(バブルソート等)を認識できた場合は補足情報として表示します。
- **実測解析 (ベンチマーク)**: 入力サイズを幾何級数(既定 2⁸〜2¹³)で変えながら実行時間を計測し、候補モデル {O(n), O(n log n), O(n log²n), O(n²), O(n³)} への最小二乗フィット(log 空間・AIC によるモデル選択)と log-log 回帰による実測指数(例: O(n^1.98) ≈ O(n²))を提示します。**入力種別(ランダム / 整列済み / 逆順)ごとに個別にオーダーを判定**するため、挿入ソートの最良ケース O(n) やクイックソートの最悪ケース O(n²) のような入力依存の挙動も実測で確認できます。
- **グラフ表示**: 入力サイズ対実行時間の log-log グラフにフィット曲線を重ねて表示します。
- **総合判定**: 理論と実測の一致・不一致を表示します(クイックソートのような平均/最悪が異なるアルゴリズムは平均オーダーとの一致で判定)。

## セットアップ

```bash
pip install -r requirements.txt
pip install -e .
```

## 使い方

```bash
streamlit run app.py
```

ブラウザで開いたページにソートアルゴリズムの Python コードを貼り付ける(または `.py` ファイルをアップロード、`examples/` のサンプルを選択)と、理論解析が即座に表示されます。「ベンチマーク実行」ボタンで実測解析が始まり、グラフと総合判定が表示されます。

## テスト

```bash
pytest -m "not slow"   # 高速テストのみ (CI 向け)
pytest                 # 実測を伴う遅いテストも含めて全部
```

## ⚠️ 注意事項 (重要)

- **本アプリは入力された Python コードを実際に実行します。** タイムアウトやプロセス分離などの基本的な保護はありますが、**サンドボックスではありません**。信頼できるコードのみを解析してください。
- 静的解析による任意コードの厳密なオーダー決定は原理的に不可能です(停止性問題)。判定できない構造は「不明」とし、置いた仮定を根拠欄に明示します。
- 実測オーダーは測定範囲・環境ノイズの影響を受けます。O(n) と O(n log n) のように近いクラスの判別が不確実な場合は注記を表示します。

## プロジェクト構成

```
src/codeevaluator/
├── models.py             # 計算量クラスと結果データ構造
├── discovery.py          # ソート関数の検出
├── analyzer/
│   ├── static.py         # AST 静的解析 (理論オーダー)
│   ├── patterns.py       # 既知アルゴリズム認識 (補助)
│   └── empirical.py      # ベンチマーク計測
├── fitting.py            # 候補モデル比較・指数フィット
├── runner.py             # 子プロセス実行・タイムアウト・正当性検査
└── plotting.py           # log-log グラフ描画
app.py                    # Streamlit アプリ
examples/                 # サンプルのソートアルゴリズム 7 種
tests/                    # pytest テスト
```
